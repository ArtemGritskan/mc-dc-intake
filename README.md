# Mining Cluster — Анкета проекта ЦОДа

Версия 1.1.5. Разработчик: Артём. Заказчик: Майнинг Кластер.

## Назначение

Плагин добавляет форму «Запрос на проектирование и строительство ЦОД» с 23 вопросами. Пользователь заполняет сведения о проекте, площадке, оборудовании и контактах, проверяет их и скачивает PDF без логотипа.

Ответы обрабатываются только в браузере. Почта, SMTP, серверная отправка, загрузка документов и база заявок не используются. PDF содержит только ответы, введённые пользователем. Все библиотеки и шрифт с кириллицей включены в плагин; внешние сервисы для скачивания не нужны.

## Установка на сайт

Требуются WordPress 6.0 или новее, PHP 7.4 или новее и современный браузер с JavaScript. Другие плагины не требуются.

1. Откройте «Плагины → Добавить плагин → Загрузить плагин».
2. Выберите `mc-dc-intake-1.1.5.zip`, установите и активируйте.
3. При первой активации создаётся страница формы с адресом `/dc-project/`. Если адрес занят, WordPress назначит свободный. Страница доступна в разделе «Страницы» и автоматически в меню не добавляется.
4. Откройте страницу и проверьте заполнение и скачивание PDF. Настраивать адрес почты не нужно.

Для размещения формы на другой странице добавьте блок «Шорткод» со значением:

```text
[mc_dc_intake]
```

В Elementor используйте виджет «Шорткод» с тем же значением. Рекомендуется широкий шаблон страницы. Шапка и подвал сайта определяются темой WordPress.

Страница формы получает `noindex` в метаданных и HTTP-заголовке. Это исключение из индексации, а не ограничение доступа по ссылке. Если шорткод вставляется программно через шаблон или нестандартный конструктор, проверьте noindex отдельно в SEO-настройках.

## Обновление с версии 1.0.0

Сохраните резервную копию собственных изменений. Замените старый плагин новым архивом через WordPress. Проверьте, что в установленной папке больше нет `includes/admin.php` и `includes/submission.php`: они удалены из новой версии. Если файлы копируются вручную, заменяйте папку плагина целиком, а не добавляйте новые файлы поверх старых.

Существующая страница и её шорткод продолжают работать. Заголовок уже созданной страницы можно изменить через «Страницы». Старые почтовые настройки не используются; почтовых обработчиков в новой версии нет. Очистите кэш сайта и браузера после обновления.

## Как заполнять форму

1. Заполните раздел «О проекте».
2. Укажите сведения о площадке и электроснабжении.
3. Укажите параметры ЦОДа.
4. Введите контактные данные.
5. На шаге «Проверка ответов» просмотрите сведения. Кнопка «Изменить» вернёт к нужному разделу.
6. Нажмите «Скачать PDF». Файл сохранится средствами браузера с именем `Майнинг-Кластер-Запрос-ЦОД.pdf`.

Все поля можно оставить незаполненными: в PDF будет «Не указано». Для технических вопросов доступна отметка «Пока неизвестно». Указанные числовые значения должны быть неотрицательными, количество стоек — целым. Если email заполнен, проверяется его формат. Выбор источника питания не добавляет дополнительных вопросов.

Ответы не сохраняются при перезагрузке страницы. Скачайте PDF до закрытия вкладки. После скачивания можно продолжить редактирование и скачать новый файл.

## Открытие на компьютере

Распакуйте весь архив и откройте `preview/index.html` через Chrome, Edge, Firefox или Safari. Сохраните структуру папок. Интернет, WordPress, Node.js и локальный сервер для этого не требуются. Локальная страница работает так же, как форма на сайте.

Для редактирования проекта в VS Code откройте `mc-dc-intake.code-workspace`.

## Ограничения полей

Ограничения работают без постоянных подписей и счётчиков под полями. Пробелы и переносы строк учитываются. Вставка текста ограничена так же, как ручной ввод. Перед переходом и скачиванием PDF значения проверяются повторно.

| Поля | Лимит |
| --- | --- |
| Срок запуска, контактное лицо, роль | 100 символов |
| Регион, адрес или координаты | 300 символов |
| Кадастровый номер | 50 символов |
| Назначение земли | 1000 символов |
| Дополнительные сведения | 2000 символов |
| Компания | 200 символов |
| Телефон | 30 символов |
| Email | 254 символа и проверка формата |
| Количество стоек | До 9 цифр, целое неотрицательное число |
| Мощность и площадь | До 9 цифр до разделителя и 3 после; запятая или точка |

Для чисел не допускаются минус, буквы и экспоненциальная запись. Эти пределы ограничивают формат ввода, а не подтверждают техническую допустимость параметров. В списках доступны только заданные варианты. Поля по-прежнему необязательные; отметка «Пока неизвестно» отключает проверку соответствующего поля.

## Обслуживание

- После обновления WordPress или темы проверяйте отображение формы на компьютере и телефоне и скачивание PDF.
- После изменения вопросов проверяйте их порядок, варианты ответов и содержимое скачанного PDF.
- Не удаляйте файлы из `assets/vendor`: они нужны для формирования PDF и кириллицы. Не удаляйте файлы лицензий.
- Если оптимизатор сайта объединяет или откладывает скрипты и скачивание перестало работать, исключите скрипты этого плагина из оптимизации и очистите кэш.
- Резервируйте исходники перед изменениями. Готовые ответы остаются только у пользователя в скачанном файле.

## Файлы проекта

| Файл | Назначение |
| --- | --- |
| `mc-dc-intake.php` | Регистрация плагина, создание страницы и noindex |
| `includes/shortcode.php` | Шорткод и подключение ресурсов |
| `config/fields.json` | Вопросы, порядок и варианты ответов |
| `assets/form.js` | Заполнение, переходы и проверка ответов |
| `assets/form.css` | Оформление и мобильная версия |
| `assets/pdf.js` | Заголовок, разделы и переносы страниц PDF |
| `assets/vendor/` | PDF-библиотеки, встроенный шрифт и лицензии |
| `preview/index.html` | Локальная страница |
| `preview/config.js` | Вопросы для локальной страницы |
| `scripts/build-preview.cjs` | Обновление локальных вопросов |
| `uninstall.php` | Удаление настроек при удалении плагина |

Правьте вопросы в `config/fields.json`, затем выполните из папки проекта:

```text
node scripts/build-preview.cjs
```

Node.js нужен только для обновления локальной конфигурации разработчиком. Установка дополнительных пакетов не требуется. WordPress читает `fields.json` напрямую. При изменении ресурсов увеличьте их версию в `includes/shortcode.php`, чтобы браузер не использовал старый кэш.

## Сборка установочного архива

Из папки проекта выполните в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-archive.ps1
```

Архив появится в папке `dist`. Скрипт включает только файлы плагина, локальную страницу, документацию и инструменты сопровождения; история Git и служебные файлы не попадают в архив. Дополнительные пакеты для сборки не нужны. Папка `dist` исключена из Git.

## Если что-то не работает

| Проблема | Решение |
| --- | --- |
| Страница пустая | Включите JavaScript, проверьте наличие всех файлов и очистите кэш |
| Вместо формы виден шорткод | Активируйте плагин и вставьте шорткод в предназначенный для него блок |
| PDF не скачивается | Проверьте файлы `assets/vendor`, разрешение браузера на скачивание и оптимизацию скриптов |
| Русские буквы отсутствуют | Восстановите `assets/vendor/font.js` из архива и очистите кэш |
| После перезагрузки поля пустые | Это предусмотренное поведение: ответы не сохраняются |
| На другом ПК не открывается | Распакуйте весь ZIP, затем откройте `preview/index.html` в браузере, а не внутри архива |

## Удаление

Деактивация отключает форму. При удалении плагина настройки удаляются, но страница остаётся, чтобы не удалять содержимое сайта автоматически. Уберите шорткод или удалите страницу вручную, если форма больше не нужна.
